## 0. 设计判断（Design Read）

**把它看作：** 台湾小工作室的实体小物店，客人从 IG／小红书点进来（手机为主），整体是「奶油底 + 薰衣草 + 实拍」的温和消费品语言。**改版方式是「保留现有风格，收紧规范」，不推倒重来。**
三个参数（taste-skill）：现状约 VARIANCE 5 / MOTION 2 / DENSITY 4 → 目标 **6 / 3 / 3**（版式稍有变化、动效克制、更多留白）。

**要保留的：** 品牌色（`--paper #fffcf5`、`--ink #292331`、`--purple #a087c1`、`--yellow #f2c879`）；OGS 字标与标题字体；实拍商品；首页 H1「給日常，一點好玩。」和第一人称、有人味的文案；所有页面都没有横向溢出；正文对比度全部达到 AA（这次在 11 个页面、两种尺寸下扫过，0 处不达标）。

**要淘汰的：** 中文页的英文全大写眉标和「01 / …」编号；10–11px 的小字；抽象几何装饰图；一个页面里 5 种 H1 字号、8 种圆角、6 种区块底色、5 种灰色文字。

## 4. 最重要的 5 个问题（按对生意的影响排序）
1. **手机上看不到购买入口：** 商品页价格在 y=1155，客制器输入框在 y=915，都在第一屏 844 之外。
2. **购买区主次颠倒、价格太小：** 不能付款的「官網下單」是视觉最强的按钮；商品卡价格只有 10px。
3. **没有统一规范：** 3 条左缘（220/256/270）、5 种 H1 字号、8 种圆角、6 种底色、5 种次级灰。
4. **客制三款没有并排：** 分页一次只显示一款；首页的三款图合计只有 340px 宽。
5. **装饰多于内容：** 英文编号眉标（最多一页 5 个）、抽象几何图、字符图标（× + −）、10–11px 小字。
