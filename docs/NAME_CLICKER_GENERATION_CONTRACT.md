# OGS 連字按壓商品：固定生成要求

版本：2026-11-23／完整背板規則。供後續開發、設計修改、網站自訂生成與交接共同遵守。適用於連字按壓款；不擅自更動其他款式。詳細數值以 `MX_P2S_STANDARD.md` 與共用參數 `src/name-clicker-mechanism.js` 為準。

## 每次修改時必須保留的描述

> 上蓋須為連續封閉外緣、平直背板與局部鍵軸安裝凹槽的一體結構。所有字形轉角、字與字之間的腰部及外圈側壁均不得因避讓鍵軸座而被切穿、開缺口或挖成多段。中央凹槽與十字套筒須同軸，凹槽周圍至少保留 1 mm 實體材料；安裝空間不足時調整安裝位置或拒絕生成，不得切外壁、縮薄套筒或任意縮放機械配合尺寸。底座鍵軸座保留四面垂直壁及局部卡扣讓位；導向壁與止擋肩位配合 4 mm 名義行程。掛耳沿用已確認的平滑、可列印下緣規則。標準機型為 Bambu Lab P2S／0.4 mm。網站預覽與 3MF 必須使用同一份已驗證的背板截面及參數。

## 必須由程式擋下的情況

- 凹槽與外緣連通、背板截面不是一個外圈加一個封閉內孔，或凹槽加最小壁厚的範圍超出完整上蓋。
- 安裝凹槽與十字柱使用不同中心，或預覽自行重建另一套背板而與匯出不一致。
- 模型生成時檢出的活動碰撞、空模型或無效實體。不得帶著錯誤繼續提供客戶下載。
- 不得用增加支撐或只在預覽遮蓋缺口來掩蓋產品幾何問題。

`nameClickerContours()` 產生並驗證 `capBack`；預覽與 3MF 直接取用它。前台收到錯誤時顯示需要調整字型／文字；匯出失敗回應 HTTP 400，不回傳有缺陷的 3MF。

## 每次修改後的驗收

1. 執行 `node tests/name-clicker-outline.mjs`，比較所有支援字型的預覽／匯出截面；必含「林予曦」與站酷快樂，以及狹窄英文字形。
2. 執行 `node tests/name-clicker-print.mjs <輸出資料夾>` 與型別檢查；確認多字形實際匯出及活動碰撞保護。
3. 涉及背板、套筒、座壁、掛耳或支撐時，檢查實際 3MF 的上下截面及 P2S 原生切片／重新開檔。確認孔內與掛耳下方沒有不當支撐、外輪廓無額外支撐墊。不得以「切片成功」代替孔位、幾何與實際支撐路徑檢查。
4. 桌面／手機實際預覽，並重建三語前台；連續建置必須一致。不得宣稱數位檢查等於新實物已驗收。
5. 提交到 Codex 開發分支，由 Mac mini／Alpha 驗收。正式站部署仍需 Ken 另行確認。本規則不授權付款、寄件或正式部署。

既有已驗證參考檔不要求重複試印。客戶文字長度／最大外形限制沿用現有設定；未經確認，不把討論中的 3 中文／6 英文或其他長度方案當成既定規則。
