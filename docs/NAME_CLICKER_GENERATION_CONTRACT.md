# OGS 三字連字按壓款製造規格

以實體列印通過的「林予曦／站酷快樂／雙軸加高底座」為基準。參考 3MF 的 SHA-256 為 `443180dff9e8511221a0ae018c45876f8b89a2e05ef2f5d6ca4e60ea225ced69`。

## 結構

- 三個中文字共用一片連續上蓋，左右兩個 MX 軸對準外側兩字。軸距隨字形調整，最小 21 mm。底座保留一道 1.4 mm 隔板。單字與兩字使用中央單軸。
- 上蓋背面保持平直，外緣完整。每個局部安裝凹槽與十字套筒同軸，凹槽外有至少 1 mm 實體壁。上蓋背部及十字套筒深度 4.993 mm，立柱外徑 5.65 mm。底座導向壁高 19.5 mm，鍵軸座頂高 10.517 mm，保留四面垂直座壁及局部卡扣讓位。
- 預覽和 3MF 共用 `nameClickerContours()` 的背板截面和軸位。模型沿 0–4 mm 行程按 0.5 mm 間隔檢查干涉。無法保留完整外緣或安全行程時，要求調整文字或字型。

## 三字版 P2S 切片

- Bambu Lab P2S／0.4 mm，紋理 PEI 板。底座和外框用 PLA Basic，色襯底與凸字用 PLA Matte。客戶設定的字型與顏色隨訂單匯出。
- 層高 0.16 mm、3 道壁、15% Gyroid。普通自動支撐、貼合型、15°、僅從列印板生成，上下間距均為 0.16 mm。保留軸槽、十字孔和掛耳下方的支撐排除區。
- `server/name-clicker-p2s-three-han.json` 保存實印專案的板材及耗材差異。切片使用網站三色通用清洗量。列印時依實際顏色配對 AMS 槽位。

修改時執行 `tests/name-clicker-outline.mjs` 及 `tests/name-clicker-print.mjs`，再用 Bambu Studio 切片並檢查支撐路徑。實體驗收適用於參考樣本及其列印配置。
