# OGS v2 · 配色修正（客制区 / 全站）

> Ken 11-27：客制区「紫色底配黑色字」很奇怪。薰衣草 `#A087C1` 仍是品牌主色，但不要大面积紫底压黑字。
> 对比度用 WCAG 2.x 公式实算（脚本见本文件末尾），文字一律 ≥ 4.5:1。

## 为什么「紫底黑字」怪
- `#A087C1` 是**中明度、低饱和**的灰紫（相对亮度 0.28）。黑字 `#2B2236` 在上面只有 **4.86:1**，刚过线；而且字和底都是偏紫的暗调，读起来发闷、像脏掉的印刷。
- 参考站里把黑字放在大色场上的（Areaware 青柠 `≈#D7F27A`）用的是**高明度、高饱和**的亮色，黑字对比 >13:1，所以看起来是故意的。中灰调的颜色做大面积文字底，参考站里一家都没有（`REFERENCES.md`）。
- 另外，客制卡里的商品图底就是浅薰衣草棚，卡片又放在中紫色场上，**三层都是紫**，商品被吃掉。

两套方案的共同点：页面主体沿用 T-A（冷瓷白 `#FBFAFD`、薰衣草棚拍底 `#EDE6F5→#DED4EC`、主文字 `#2B2236`、次文字 `#5F566C`、成交黄 `#F2C879`）；**`#A087C1` 不再当文字底**，只当「色」用：商品棚拍底、选中状态、线条、图标、小面积色块。

## 方案一「深梅舞台」（推荐）
客制区换成跟主文字同色系的深梅色，像一个打了光的小舞台；薰衣草变成舞台上的光（细线、选中框、图标），商品图的浅薰衣草棚底在深色上会自己亮起来。

| 角色 | Hex | 用在哪 | 对比度 |
|---|---|---|---|
| 舞台底 `--stage` | `#2A2135` | 客制区整块底（首页客制区、客制页首屏） | — |
| 舞台卡 `--stage-2` | `#3A2E4A` | 客制款式卡的文字区、输入框底 | — |
| 舞台主文字 | `#FBFAFD` | 标题、款名 | 对 stage **14.77:1**；对 stage-2 **12.10:1** |
| 舞台次文字 | `#D8CDE8` | 说明句 | 对 stage **10.10:1**；对 stage-2 **8.28:1** |
| 品牌紫（光） | `#A087C1` | 输入框聚焦框、选中框、图标、工期胶囊描边 | 对 stage **4.92:1**（作文字也过线） |
| 成交黄 | `#F2C879` / 字 `#2B2236` | 舞台上的主按钮 | 按钮字 **9.61:1**；按钮对 stage 9.74:1 |
| 页面底 / 主文字 / 次文字 | `#FBFAFD` / `#2B2236` / `#5F566C` | 其余所有区块 | 14.77 / 6.66 |
| 价格、链接 `--brand-ink` | `#5E4382` | 价格、文字按钮 | 对页面底 **7.76:1** |
| 商品棚拍底 | `#EDE6F5 → #DED4EC` | 所有商品图底 | 次文字在上面 5.68:1 |

- **使用比例：** 页面底 55%、棚拍底与浅区块 22%、深梅舞台 12%、文字 6%、薰衣草（线条、选中、图标）3%、黄 2%。
- **每页最多 1 块舞台**（首页客制区、客制页首屏、商品页不用）。
- **为什么比紫底黑字好：** 文字对比从 4.86 升到 14.77；底、卡、商品图三层明度拉开（深 → 中深 → 浅），商品是画面里最亮的东西；薰衣草从「一大片」变成「打在商品上的光」，品牌感反而更集中。
- **风险：** 白天调为主的站中间有一块深色，如果 Ken 觉得太重，可以把舞台只留在客制页首屏、首页改用方案二。

## 方案二「薰衣草雾」
全站保持亮色，客制区换成比棚拍底更浅的雾紫，白卡浮在上面；薰衣草只在选中、标签和图标出现，文字一律深色。

| 角色 | Hex | 用在哪 | 对比度 |
|---|---|---|---|
| 雾底 `--mist` | `#F3EEFA` | 客制区整块底 | — |
| 卡片 | `#FFFFFF` | 款式卡 | — |
| 主文字 | `#2B2236` | 标题、款名 | 对 mist **13.30:1**；对白 15.16:1 |
| 次文字 | `#5F566C` | 说明 | 对 mist **6.07:1**；对白 6.92:1 |
| 标签 | 底 `#E7DDF4` / 字 `#4A3368` | 工期、价格胶囊 | **8.17:1** |
| 品牌紫 | `#A087C1` | 输入框聚焦框、选中框、图标 | 图形用 |
| 深紫按钮（可选） | 底 `#5E4382` / 字 `#FFFFFF` | 次级实心按钮 | **8.07:1** |
| 价格、链接 | `#5E4382` | 同方案一 | 对 mist 7.08:1 |

- **使用比例：** 页面底 60%、雾底与棚拍底 30%、文字 6%、薰衣草 2%、黄 2%。
- **为什么比紫底黑字好：** 不再有中灰紫的大面积底，文字全部 ≥ 6:1；整站一个亮调，不会有「换了一个网站」的感觉。
- **风险：** 雾底、棚拍底、卡片都很浅，客制区跟其他区块的分界弱，品牌辨识度主要靠商品图的薰衣草底；接近方向 B 的安静，Ken 说要「有设计感」时力道可能不够。

## 一句话差异与推荐
- 方案一：客制区是一块深梅色的「舞台」，薰衣草当光，对比最强、最有记忆点。
- 方案二：全站都是亮的，客制区只是更浅的雾紫，最安全、最安静。
- **推荐方案一**，效果稿 `mockups/` 按方案一做；客制总页另出一张方案二桌面稿 `mockups/custom_d_mist.png` 方便对照。

## 对比度脚本
```python
def L(h):
    c=[int(h[i:i+2],16)/255 for i in (0,2,4)]
    c=[x/12.92 if x<=0.03928 else ((x+0.055)/1.055)**2.4 for x in c]
    return 0.2126*c[0]+0.7152*c[1]+0.0722*c[2]
def cr(a,b): a,b=L(a),L(b); return (max(a,b)+.05)/(min(a,b)+.05)
# cr('fbfafd','2a2135') = 14.77；cr('2b2236','a087c1') = 4.86
```
