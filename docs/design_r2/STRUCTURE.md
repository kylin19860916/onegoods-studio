# OGS v2 · 结构方案（2026-11-27 · Alpha · 待 Ken 确认）

> 起因：Ken 11-27 15:07 看了方向 A，说「只在原有结构上调样式不够，要功能性更强、同时有设计感」。所以这份先重排**结构**：每个模块只回答「客人在这里要完成什么」，只放跟「看到 → 选/客制 → 下单 → 收货」直接有关的功能。

> 标记：**【新增】【删除】【合并】【改】【保留】**；后端：**需後端** = 要改数据库、订单或 API；**前端** = 只改页面和 JS；**内容** = 要 Ken 给资料或照片。「一期」本轮可做，「二期」等后端。

## 0. 现站已有的事实（下面所有文案都只用这些）
- 现货：Keynade MX NT$499、財屎運 NT$79、Enerkey 磁吸雙件鑰匙扣 NT$120、攪屎棍 NT$79。
- 付款：官網刷卡（绿界，已通过）；另有 7-11 賣貨便、蝦皮。
- 配送：结账页现在是「7-ELEVEN 超商取貨 NT$60」「黑貓宅配 NT$100」（11-27 抓正式站 HTML；**上线前要再对一次结账页**）。
- 客制：三款（名牌款／按壓款／關節字塊），工期「3 天內出貨」（K6）；**价格还没查到**，查不到的格子隐藏。
- 退换：`purchase-policy`「收受商品後七日內」可解除契约；客制如涉及例外「須於下單前另行告知」；瑕疵寄照片到客服信箱。
- 现在的「購物袋」只能放**一件商品**（从商品页进结账页，结账页内选数量和配送），没有多件购物车。

## 7. 一期 / 二期

- **一期（只动前端，本轮可交 Codex）：** 服务条、首页与客制页名字输入框带 `?name=`、首页「怎麼買」+ 常见问题、好物页「可客製」筛选 + 排序 + 件数、商品页数量提前（`?qty=`）、配送退换摘要、展开列、客制入口条、其他好物、客制器订单摘要和拼写确认、页头删「首頁」。
- **二期（需後端）：** 多件购物袋（页头图标、卡片「加入購物袋」、客制设计存成订单项）、客制器实时价格（价格表）。
- **要 Ken 给的内容：** 客制三款价格（K6）、三款尺寸、现货出货天数（目前只知道客制是 3 天內）、拼写确认那句话能不能用、运费数字以哪个为准。
