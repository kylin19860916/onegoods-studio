## 模型與照片

- 四款用實際客製器幾何。三張主要成品共用 85mm 鏡頭、30°方位、18°俯角、155.078mm 距離和畫布 78% 基準線。保留實物比例後，Mia、飛、LEO 的占比為 59.6%、61.2%、64.0%。ABC 備用版距離 255.879mm，讓三鍵完整入鏡。
- 站上使用 1024／2048 透明 WebP。獨立陰影、相機與用色 JSON 隨分支保存，2048 PNG 與兩種底色的驗收圖在附件。Mia 主體的同輸入重跑，正規化平均像素差為 0.000004%。沒有以同一方法重跑其餘三款作像素比對。
- 四張現貨使用原商品照片去背，輸出 800／1600 兩檔。1600 版四角差最大 2 級。首頁與好物組合照已標「示意合成」，來源記錄在 `public/assets/r2-studio/source.json`。
